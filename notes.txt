# Train/Split Method
1. Test the method on several periods (walk-forward). Train on everything up to a date, test the next block,
    then roll forward: for example train to 2019Q4 and test 2020Q4–2021Q4,
    then train to 2020Q4 and test the next year, and so on. Keep the 3-quarter gap each time.
    Every quarter after the first training block becomes test data once, so you get several out-of-sample
    results across different regimes, not one.
2. Once the method holds up, choose the final models on all the data.
    The holdout's job is to show that the selection method works, not to fix which
    models you finally use. After validation, run the same selection over the full
    2016Q4–2025Q2 sample. That uses every quarter for the final choice, which is the
    benefit you're after. The trade-off: no untouched holdout is left to judge those final picks,
    so their expected performance comes from the walk-forward results.
3. Add new quarters as the data come in, using the same method.
